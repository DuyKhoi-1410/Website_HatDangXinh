# HẠT DÁNG XINH – Website Thương Mại Điện Tử Snack Dinh Dưỡng Cao Cấp

> **Concept:** PREMIUM ORGANIC · EAT CLEAN · LIVE BEAUTIFUL  
> **Phong cách:** Modern Editorial & Luxury Organic (lấy cảm hứng từ Oxyfree Danang)

---

## 🌟 Giới Thiệu Dự Án

**HẠT DÁNG XINH** là website thương mại điện tử chuyên cung cấp các dòng snack dinh dưỡng, hạt sấy nguyên vị, combo ăn nhẹ theo nhịp sinh học và set quà tặng sức khỏe thượng hạng tại Việt Nam.

Website được xây dựng với trải nghiệm người dùng cao cấp:
- **Hiệu ứng Parallax 3D & Hạt Bay**: Background hạt điều chuyển động bồng bềnh tự nhiên và dao động sinh động khi cuộn trang.
- **Hệ thống E-Commerce hoàn chỉnh**: Giỏ hàng lưu trữ LocalStorage, thanh tiến trình Freeship, Modal chi tiết sản phẩm, bảng đối chiếu calo & dinh dưỡng, biểu mẫu thanh toán COD / Chuyển khoản ngân hàng và cấp mã đơn hàng thực tế kèm pháo hoa ăn mừng (`canvas-confetti`).
- **Hình ảnh bao bì thực tế 100%**: Đầy đủ 5 dòng snack lẻ 30k và bộ quà tặng 3 hũ 249k.

## 🚀 Công Nghệ Sử Dụng

- **Frontend**: React 19, Vite 8
- **Styling**: Tailwind CSS v4, Glassmorphism, CSS Custom Properties
- **Animation**: Framer Motion (Parallax Scroll, Spring Physics, Floating Loops)
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **State Management**: React Context API + LocalStorage persistence
